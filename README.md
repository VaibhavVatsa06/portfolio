# Vaibhav Vatsa — Portfolio

A personal developer portfolio website showcasing my experience, projects, skills, and achievements.

## 🔗 Live Preview

> Deploy via GitHub Pages or any static host to get a live URL.

## 📁 Project Structure

```
portfolio/
├── index.html              # Main HTML file
├── style.css               # All styles
├── script.js               # Scroll animations, typing effect, nav
├── Self.jpg.jpeg           # Profile photo
├── Vaibhav_vatsa___Software.pdf  # Resume
├── hack-hackathon.jpg.JPG  # Hack-O-Rama image
├── hack-aventus2.jpg.jpg   # Aventus 2.0 image
├── hack-aventus3.jpg.jpg   # Aventus 3.0 image
├── vol-web3.jpg.jpg        # Web-3 Community image
└── vol-numerano.jpg.JPG    # NUMERANO Club image
```

## ✨ Features

- Fully responsive — mobile, tablet, desktop
- Typing animation in hero section
- Scroll-triggered fade-in animations
- Sticky frosted-glass navbar
- Skill icons via Devicons CDN
- Scroll-to-top button
- Resume opens in new tab (same as GitHub / LinkedIn)

## 🛠️ Tech Stack

Built with plain **HTML5**, **CSS3**, and **vanilla JavaScript** — no frameworks, no build step.

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom, no framework) |
| Scripts | Vanilla JavaScript |
| Icons | [Devicons CDN](https://devicon.dev/) |
| Fonts | Inter + Fira Code (Google Fonts) |

## 📌 Sections

- **Hero** — Name, role, bio, social links, resume
- **About** — Brief intro + quick info
- **Experience** — BlueStock, Startup Folks
- **Projects** — 4 projects with GitHub links
- **Skills** — 19 skill icons in a flat grid
- **Achievements** — 3 hackathon cards with images
- **Certifications** — NPTEL (IIT Kharagpur), Google
- **Education** — DSCE B.E. ECE
- **Volunteer Work** — Web-3 Community, NUMERANO
- **Contact** — Email, GitHub, LinkedIn, Resume

## 🚀 Getting Started

No installation needed. Just open `index.html` in any browser:

```bash
# Clone the repo
git clone https://github.com/VaibhavVatsa06/portfolio.git

# Open in browser
cd portfolio
open index.html   # macOS
start index.html  # Windows
```
