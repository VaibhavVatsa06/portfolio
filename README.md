# vaibhav vatsa — portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript. No frameworks, no build tools — just clean code.

**Live at:** [github.com/VaibhavVatsa06/portfolio( https://vaibhavvatsa06.github.io/portfolio/)

---

## stack

- HTML5, CSS3, Vanilla JS
- [Devicons](https://devicon.dev/) for skill logos
- Inter + Fira Code via Google Fonts

## sections

Experience · Projects · Skills · Achievements · Certifications · Education · Volunteer Work · Contact

## run locally

```bash
git clone https://github.com/VaibhavVatsa06/portfolio.git
cd portfolio
# open index.html in your browser
```

No dependencies. No install. Just open and go.
